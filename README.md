# Guido – simulatore di guida

Simulatore di guida nel browser (Three.js). Si apre da GitHub Pages: `https://hellogitty01.github.io/Guido/`.

Mappe disponibili dal menu:
- **Milano e dintorni**: mondo generato con città, campagna e traffico.
- **Nord-Ovest reale**: Milano, Como e Biella da OpenStreetMap con quote reali.
- **Centri città 3D fotorealistici (Google)**: richiede una chiave API Google (Map Tiles API), che si incolla nel menu e resta solo nel browser.
